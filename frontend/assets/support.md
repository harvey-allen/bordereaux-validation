# Support

## Getting Started

1. Select a validation pack (Premium, Claims, or Risk).
2. Configure the required territory.
3. Map your source columns to the validation schema fields.
4. Optionally use **Field Estimation** to automatically suggest mappings using fuzzy matching.
5. Review and confirm mappings.
6. Run validation.

---

## Validation

The platform includes 250+ validation rules covering:

* Completeness
* Data types and formats
* Value constraints
* Business logic

Results are categorised as:

* Critical
* Error
* Warning

## Troubleshooting

**No results returned**

* Check field mappings
* Confirm validation has been run

**Unexpected failures**

* Review the validation rule description
* Check source data values and formats

**Incorrect field mappings**

* Review and update mappings
* Re-run validation
